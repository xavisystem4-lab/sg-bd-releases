# SG-BD — instaladores

APK de **SG-BD** (menús para Soft Restaurant) · Desarrollado por **SoftGala**.

Este repositorio solo contiene los instaladores publicados en **Releases**. El botón **Actualizar** de la app
descarga de aquí la versión más reciente (`SG-BD-x.y.z.apk`). El código fuente no se publica aquí.

La app requiere una licencia de **Licencias SoftGala** para este teléfono o tablet.
